Unsafe HTML reflection

The server inserts attacker-controlled GET input into the HTML response without encoding.

if mode == 'vulnerable':

THE ONE IMPLEMENTED FIX

HTML output encoding

Escaping HTML-sensitive characters makes script tags display as ordinary text instead of executing.

if mode == 'secure':
    reflected = html.escape(
        query, quote=True)  # SAFE
